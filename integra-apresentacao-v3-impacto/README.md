# InTEGRA — Site de Apresentação v3

Projeto totalmente independente do site público atual da InTEGRA.

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta `integra-apresentacao-v3-impacto`.
3. Faça duplo clique em `index.html`.

Para trabalhar no Visual Studio Code:
1. Abra o Visual Studio Code.
2. Ficheiro > Abrir Pasta.
3. Escolha esta pasta.
4. Para uma visualização mais fiável dos vídeos, use a extensão gratuita Live Server.

## Vídeos
Coloque os seus ficheiros MP4 dentro da pasta `videos` com estes nomes:

- 01-porque-criei-a-integra.mp4
- 02-o-problema.mp4
- 03-o-que-e-a-integra.mp4
- 04-porque-sera-gratuita.mp4
- 05-modelo-sustentavel.mp4
- 06-porque-uma-associacao.mp4
- 07-porque-portugal.mp4
- 08-o-que-procuramos.mp4

## Logótipo
O ficheiro `assets/logo-integra.png` é a imagem enviada pelo utilizador e usada nesta versão.
